# DCF Valuation Model (FCFF)

This project implements a Discounted Cash Flow (DCF) valuation using the
Free Cash Flow to Firm (FCFF) approach in Excel. The model includes
historical financial analysis, forward projections, FCFF calculation,
and enterprise valuation using a terminal value.

The valuation is presented at the enterprise value level due to the
unavailability of debt and shares outstanding data.
